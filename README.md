# LOVE ROADWAYS V3 — COMPACT PLAYER

The video player is now small and placed inside the bottom music player's left media/title area instead of appearing as a large floating window.

Run:
```bash
py -m pip install -r requirements.txt
py app.py
```
Open `http://127.0.0.1:5000`.

The compact embedded YouTube player remains interactive and the custom seek/volume controls stay below it.
